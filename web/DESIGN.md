# 걸어봄 디자인 기준 (DESIGN.md)

이 문서는 화면을 만드는 사람이 매번 다시 정하지 않도록 값을 고정한다.
제품·계산·API 의미는 `docs/걸어봄_확정설계_v2.4.md`가 기준이며, 이 문서는 그 의미를 **어떻게 보이게 할지**만 정한다.
원본은 `걸어봄_프론트_UIUX_설계_v1.md` F절(2026-09-12)이고, 같은 날 승인된 보정(Claude Design 반영분)을 아래 "보정 기록"에 적었다.
값을 바꾸려면 `src/styles/tokens.css`와 이 문서를 같은 PR에서 고친다.

## 1. 원칙

1. **숫자가 주인공이다.** 화면에서 가장 큰 글자는 항상 분(分) 숫자다. 제목·로고·장식이 그보다 커지지 않는다.
2. **상태는 값이 아니다.** `확인 필요`·`도달 경로 없음`·`반경 내 없음`·`집계 미완료`는 숫자와 크기·글꼴·아이콘이 다르고, 색만으로 구분하지 않는다. 표시 분기는 항상 API `status`·`code`다(v2.4 4-5).
3. **지도를 가리지 않는다.** 오버레이는 상단 검색바와 하단 시트 두 곳에만 있고, 핀은 항상 가시영역에 남는다.
4. **한 번에 하나의 색.** 딥 블루 하나가 CTA·선택·경로선·강조를 맡는다. 경고·오류·회색은 상태 전용이며 장식에 쓰지 않는다.
5. **"예상"과 "기준일"은 어디에나.** 결과를 보이는 모든 화면에 데이터 기준일과 예상 시간 문구가 있다.
6. **말은 짧고 구체적으로.** 문장 하나에 일 하나. 내부 용어(OSRM·snap·density·fid)는 화면에 나오지 않는다.

## 2. 시각 방향

흰 종이 위의 계기판. 지도가 유일한 컬러 면이고, 시트·패널은 흰 바탕에 가는 구분선과 표형 숫자만 놓인다. 카드 안에 카드를 두지 않는다. 그라디언트·블러·큰 그림자·일러스트를 쓰지 않는다.

의미 색은 **텍스트+아이콘에만** 쓰고 배경 틴트(`-100`)는 오류 카드·경고 줄에만 쓴다. 표 셀 배경에는 `--accent-100`만 허용.
`--muted-100` 위에 텍스트를 놓지 않는다(대비 4.36:1 미달). 다크 모드는 범위 밖. `color-scheme: light`.
마커 이미지(SVG 데이터 URI)는 CSS 변수를 읽지 못하므로 `src/kakao/useKakaoMap.ts`가 `--accent-600`·`--paper` 값을 한 번 복제한다.

## 4. 타이포그래피

시스템 글꼴만 쓴다(웹폰트 없음). 굵기는 400·600 두 단계.

| 토큰 | 크기/행간 | 용도 |
|---|---|---|
| `--t-caption` | 12/16 | 좌표·기준일·설명 문장 |
| `--t-body-s` | 14/20 | 시설명·주소·상태 문구(600)·비교표 시간 셀(보정) |
| `--t-body` | 16/24 | 항목명·입력·버튼 |
| `--t-title` | 18/26 | 시트 헤더 라벨·다이얼로그 제목 |
| `--t-num-m` | 22/28 | RoutePanel 분 |
| `--t-num-l` | 28/32 (≤359px: 24/28) | 결과 행 분·밀도 값 |

숫자는 항상 `tabular-nums`. 단위(분·m·곳)는 숫자보다 **두 단계** 작은 토큰(14px), 같은 baseline(보정: 단위 크기 축소). `word-break: keep-all`. 라벨·주소 1줄 ellipsis, 상태 문구 2줄까지.

## 5. 간격·폭·모서리·선·그림자

`--s-1…--s-10` = 4·8·12·16·20·24·32·40. `--w-panel` 400(≥1440: 440), `--w-sheet-content` 600, `--w-compare` 960, `--w-prose` 680.
`--r-1` 4(태그) · `--r-2` 8(버튼·입력·오류 카드) · `--r-3` 12(플로팅 컨트롤) · `--r-4` 16(시트 상단만).
`--shadow-1`(플로팅 컨트롤·검색바) · `--shadow-2`(시트). 시트 안 요소에는 그림자 없음. 구분선은 `1px solid var(--line)` 하나뿐.
시트·패널 좌우 패딩 `--pad-x` = 12(≤359) / 16 / 20(≥960).

## 6. 아이콘

20px 그리드, 1.75px 스트로크, 둥근 끝. 자체 SVG(`src/ui/Icon.tsx`). 카테고리 6·상태 5·UI 아이콘. 의미 아이콘은 `aria-hidden`, 아이콘 단독 버튼은 `aria-label`.

## 7. 지도 위 오버레이

상단 검색바(border 최소 + `--shadow-1`, 보정)·우측 컨트롤·하단 시트 세 곳만. 핀은 **확정 좌표가 바뀔 때만** 시트 위 가시영역 세로 중앙으로 이동한다. 핀 드래그·탭·스냅 변화·행 확장에는 지도가 움직이지 않는다. 경로 `setBounds` 하단 패딩 = 시트 높이 + 24, 상단 패딩 = 상단바 72 + 24(모바일; 검색바 뒤로 선·목적지 점이 지나가지 않게, 2026-09-12 실제 카카오 QA), 좌우 24.
마커: 출발 핀 32×40(pending 윤곽선 / 확정 채움), 목적지 점 12px. 폴리라인 accent 5px 위, 흰 케이싱 9px 아래.

## 8. 카드 · 9. 버튼 · 10. 입력

시트·패널 안에서는 카드를 쓰지 않는다(오류 카드·다이얼로그만 허용, `--r-2`, 1px 선, 그림자 없음).
버튼 5종: primary 48(화면당 하나) / secondary 44 / text 44 / icon 44×44 / floating 44 `--r-3`. hover는 데스크톱만 배경 1단계.
입력 48, 포커스는 `box-shadow` 방식 2px accent(시프트 없음), 글자 16px, `type="search"`, `enterkeyhint="search"`. 결과 항목 56.

## 11. Bottom sheet

peek 132(+safe-area) / half `clamp(320, 52dvh, 520)` / full `100dvh − 72 − 8`. handle 36×4(보정 D: 대비 강화), 영역 24. `transform`만 애니메이션(240ms). 드래그 중 트랜지션 없음.
**스냅과 경로 상태는 분리한다**(보정 E). 행 확장·경로 표시가 스냅을 옮기지 않는다. RoutePanel은 peek일 때만, half·full에서는 확장된 행이 "경로 표시 중"을 말한다. 데스크톱은 헤더 아래 고정.

## 12. 결과 행

56px. 좌 아이콘 20 + 간격 12 + 이름 16/400. 우측 값 우정렬 최소폭 72, **세로 중앙 정렬**(보정). `status != ok`: 상태 아이콘 20 + 문구 14/600. 두 번째 줄: `ok` → `{name} · {walk_m}m`(우회면 `직선 n m · 도보 m m` 대체) / `uncertain`(A) → 시설명만 / 그 외 없음. 확장 시 행 배경 `--accent-100`(시트 패딩까지 bleed), top3 각 48. 행 순서 고정.
밀도 행: "카페·음식점" 옆 인라인 보조 "도보 10분 안"(보정).

## 13. 상태 표현

| API | 문구 | 형태 |
|---|---|---|
| nearest `ok` | `{분}분` | 28px 숫자 + 14px 단위 |
| nearest `uncertain` | 확인 필요 | 14/600 `--warn-700` + 삼각 아이콘 |
| nearest `unreachable` | 도달 경로 없음 | 14/600 `--muted-700` + 끊긴 길 아이콘 |
| nearest `none` | 반경 내 없음 | 14/600 `--muted-700` + 대시 원 아이콘 |
| density `capped` / `complete` / `incomplete` | 20+ / `{count}`+곳 / 집계 미완료 | 28px / 28px+14px / 14/600 + 반원 아이콘 |
| `snap_warning` | 가장 가까운 보행로가 {n}m 떨어져 있어요. 도보시간이 실제와 다를 수 있어요. | `--warn-100` 배경 12px, TrustLine 위 |

SummaryStrip(peek)에서만 축약 토큰(확인/불가/없음/미완료). **비교표에서는 쓰지 않는다**(보정 B). TrustLine은 헤더 인접(보정 A, 하단 이동 기각). poi_date 라벨은 v2.4 확정 문구 `데이터 기준일(가장 오래된 자료): {poi_date}`, 보조 설명 문장은 Week 3 결과 UI에 넣지 않는다. 이 라벨은 어느 폭에서도 첫 줄(`{region.label} · 검수 상태`)에 이어 붙지 않으므로 **항상 둘째 줄, 구분점 없이** 둔다(2026-09-12 QA).

## 14. 비교 강조

강조 셀: 600 `--accent-600` + 하단 2px + 배경 `--accent-100` + sr-only "가장 짧음/많음". **동률은 모두 무강조·우세 수 미포함**(2026-09-12 확정). 비교 대상 2개 미만 무강조. 시간 셀 14px(보정). 후보 열 `--compare-col` 76(72~80 허용), 첫 열 88 sticky, 가로 스크롤 정상 동작(360 무스크롤 강제 안 함, 보정 B). 표 최소 폭 = 첫 열 + 열 수 × `--compare-col-min` 72 — 그보다 좁으면 컨테이너가 가로 스크롤한다(열이 72 아래로 눌리지 않는다). 셀 좌우 패딩 4(좌표 `127.14020` 한 줄, 상태 문구 2줄). ≥768: 첫 열 `--compare-first-col-wide` 120, 후보 열 최소 `--compare-col-wide` 160. 설명 카피 추가 없음.

## 15~19. 빈·로딩·오류 · 모션 · Reduced motion · 포커스 · 터치

빈 상태 한 문장 + 행동 하나. 로딩은 스켈레톤 6행(반짝임 없음) + 문장 하나, 인라인 스피너 16px. 오류 카드 제목 16/600 `--danger-700`(지원 지역 밖·스냅 실패는 ink), 코드 미표시.
모션: 시트 스냅 240 / 결과 교체 120 / 행 확장 160 / 담기·토스트 150·160. 그 외 없음. `prefers-reduced-motion`에서 토큰 duration 0.
`:focus-visible` 2px `--focus`. 다이얼로그는 네이티브 `<dialog>`. 지도 캔버스 `tabindex=-1`. 터치 타깃 44 이상, 행 56.

## 20. 반응형

## 21. UI writing

"~해요" 체. 한 문장 = 한 정보. 느낌표·이모지 없음. 시스템 명명 금지. 좌표 표기 `36.47130, 127.14020`(lat, lng). 확정 문장은 글자 하나도 바꾸지 않는다. **원 설계·계약에 없는 설명 문장을 새로 만들지 않는다**(2026-09-12 확정: 기존 `NEAREST_STATUS_NOTE`·`POI_DATE_NOTE` 삭제).
